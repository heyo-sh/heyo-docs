# Text Styling

Use regular Markdown for most documentation. Keep the text short and let
headings show readers where to look next.

## Add headings

Use `##` for a main section and `###` only for a useful subsection.

```md
## Configure navigation

Add pages in the order readers should follow.

### Add an external resource

Link to a resource outside your documentation.
```

## Highlight important text

Use **bold** for an important choice and inline `code` for values readers need
to copy.

```md
Set `content: "content"` in `heyo-docs.config.ts`.

Run `bun run build` before you publish.
```

## Write useful links

Use the destination as the link text. It is easier to scan than a raw URL.

Read the [Quickstart](/quickstart) before changing
[site configuration](/configuration).

> Keep one idea in each short paragraph.
