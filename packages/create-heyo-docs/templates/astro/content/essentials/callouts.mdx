# Callouts

Use a callout when a reader should not miss a detail.

## Add a tip

<Callout type="tip" title="Keep examples focused">
  Show one idea at a time so readers can apply it quickly.
</Callout>

## Choose a type

| Type                  | Use it for             |
| --------------------- | ---------------------- |
| `info` or `note`      | Helpful context        |
| `tip`                 | A recommended approach |
| `check`               | A successful result    |
| `warning` or `danger` | A real consequence     |

<Callout type="warning" title="Preview before publishing">
  Run the production build after changing navigation or MDX.
</Callout>

## Keep it short

<Callout type="info" title="Configuration and content work together">
  Navigation belongs in <code>heyo-docs.config.ts</code>. Titles and
  descriptions belong in page frontmatter.
</Callout>
