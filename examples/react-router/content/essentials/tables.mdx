# Tables

Use a table to compare the same details across a small number of options.

## Add a table

| Setting   | Purpose                                | Example                      |
| --------- | -------------------------------------- | ---------------------------- |
| `content` | Directory containing MDX source files. | `"content"`                  |
| `theme`   | Built-in documentation theme.          | `"grain"`                    |
| `mode`    | Initial color preference.              | `"system"`                   |
| `siteUrl` | Canonical public site origin.          | `"https://docs.example.com"` |

## Keep it readable

Use short headings and short cells. Put long explanations in a section below
the table.

| Use a table for        | Use a section for      |
| ---------------------- | ---------------------- |
| Compact comparisons    | A multi-step procedure |
| Option defaults        | A detailed explanation |
| Short reference values | A large code example   |

Use a numbered list when readers must act in a specific order.
