# API overview

The API reference is generated from `openapi.json`. Use the endpoint pages to
enter parameters, send a request, and copy a cURL or JavaScript example.

## Authentication

The example API uses a Bearer token. Enter it once on any protected endpoint;
Heyo Docs keeps it in this browser while you move between API pages.

## Custom pages first

This ordinary MDX page belongs to the OpenAPI group. Its section is configured
before the generated endpoint sections, so it always appears at the top of the
sidebar.
