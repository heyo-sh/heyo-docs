# Lists

Use a list when readers need to scan choices or follow a short sequence.

## Add a bullet list

Use bullets when the order does not matter.

- Keep MDX pages in the `content` directory.
- Add important routes to `heyo-docs.config.ts`.
- Build the project before publishing.

## Add numbered steps

Use numbers when the order matters.

1. Create an MDX file.
2. Add its path to a sidebar section.
3. Start the development server.
4. Review the rendered route.

## Add one level when needed

Use a nested list only for a direct relationship.

- Prepare the release:
  - Review the changed pages.
  - Confirm navigation order.
  - Run the production build.

Use `Steps` when each step needs a command or more explanation.
