# MDX components

Every component below is available without an import. The examples show every visual variant, so this page is also the reference for the documentation theme.

## Button

`Button` uses the same shadcn component as the theme. It accepts `variant` and `size`, and uses `href` when the button should navigate. Use `align="left"`, `"center"`, or `"right"` to position it in the documentation column.

<Button href="/getting-started" variant="default" size="lg">
  Get started
</Button>
