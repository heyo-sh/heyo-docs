# Getting started

Install dependencies with your chosen package manager and start the development server.

## Create a page

Create `content/guides/deploying.mdx` to get the `/guides/deploying` route. Its frontmatter controls its title and description.

## Configure the documentation

Use `heyo-docs.config.ts` to change the title, colors, tabs, sidebar groups, footer links and selected theme without regenerating your project. Add pages or directories to a section's `pages` list to control the sidebar order.
